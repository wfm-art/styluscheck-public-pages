Privacy Policy

How information is used to manage classroom equipment.

StylusCheck is a personal, non-commercial educational application developed and used by a teacher to manage resources in their own classroom. It is not a commercial product or a publicly offered service. StylusCheck has no advertising and does not sell data.

InformationPurposeAccessServicesRecords

1. Information used

StylusCheck uses student names and internal identifiers, class enrollment and assignment information, classroom locations, and school schedules. It also uses equipment identifiers, resource types, availability, borrower references, and checkout and return records, including timestamps and transaction status.

Staff identifiers, permissions, temporary session information, label designs and label records support authorized operation. Technical records can include errors, request identifiers and optional performance measurements.

2. Why information is used

This information is used to organize equipment, record assignments, process authorized checkouts and returns, show resource availability, and maintain a history of equipment use. Access and technical information help control access and troubleshoot problems.

Student information is used for classroom resource management, not advertising or commercial promotion.

3. Who can access information

Operational information is available to authorized users according to the application's access controls. The teacher responsible for StylusCheck manages access to the application and its underlying records. People granted access to the underlying Google files may also be able to access those records.

These public information pages do not display student records or provide transaction tools.

4. Services and device features

Google Sheets stores classroom resource, assignment and transaction records, as well as saved label designs. Google Apps Script processes authorized requests and manages temporary access state and execution logs. Firebase Hosting delivers the application. Firebase Realtime Database carries operational update signals, including opaque references, resource state and timestamps; those references should not be considered anonymous data.

Google identity and cloud services support authorized backend communication. These providers process information needed to operate StylusCheck. Requests to hosting and service providers may include technical metadata such as IP addresses and browser information.

The operational application loads a QR decoding library from unpkg, which may receive ordinary request metadata. When camera scanning is used, the browser decodes QR labels and sends decoded label information to the backend for validation and processing. The public Home and Privacy Policy pages do not request camera access or load that library.

The application uses browser session storage for session and interface state and optional short-lived diagnostics. Older saved label templates may remain in local storage. These two public pages contain no advertising, analytics scripts or application-storage access.

5. Records

Resource assignments and transaction history are retained as operational records. Changes to a resource or deletion of a saved label template do not necessarily erase earlier transaction or design revisions. Clearing browser storage does not delete centralized records.

The teacher using StylusCheck manages the classroom records. This page does not promise a fixed automatic deletion period or that removing one record erases every related history entry.
